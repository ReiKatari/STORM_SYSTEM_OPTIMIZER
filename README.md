## ⚡ О проекте

**STORM SYSTEM OPTIMIZER v0.0.3** — это системный оптимизатор нового поколения на нативном движке **WPF (.NET 8 LTS)**. Программа проводит глубокий многопоточный анализ всей системы, предоставляет интерактивный менеджер процессов с базой знаний и рекомендациями, диагностику накопителей и S.M.A.R.T. с оптимизацией TRIM/дефрагментацией, глубокую калибровку TCP/IP и DNS сетевого стека, очищает скрытый мусор и оптимизирует службы без риска повреждения Windows.

---

## 🚀 Новые возможности и исправления в версии 0.0.3

1. **💾 Диагностика дисков, S.M.A.R.T. и аппаратная оптимизация / TRIM**:
   - Полная информация по каждому накопителю: модель, интерфейс (NVMe SSD, SATA SSD, HDD), объем, занятое/свободное место, файловая система.
   - Оценка процента здоровья (Health %) и температурные показатели.
   - **Глубокая оптимизация**: аппаратная команда TRIM и консолидация блоков для SSD, глубокая дефрагментация секторов для HDD с выводом процесса в интерактивную консоль.

2. **⚙️ Исправление и полная стабилизация «Служб Windows»**:
   - Устранены любые вылеты при обращении к службам за счет полной изоляции Win32 исключений и прямого реестрового fallback.
   - Корректное применение всех 4 профилей: **⚖️ Рекомендуемый (Balanced)**, **🎮 Игровой (Gaming)**, **⚡ Экстремальный (Extreme)**, **↺ По умолчанию (Default)**.
   - Цветные бейджи статусов служб (🟢 Работает, ⚪ Остановлена, 🔴 Отключена).

3. **🎨 Кастомные модальные окна `StormMessageBox`**:
   - Все стандартные белые системные диалоги заменены на единое стилизованное кибер-окно с неоновым свечением, иконками статусов и поддержкой активной темы.

4. **🚀 Глубокая стилизация «Автозагрузки»**:
   - Полная адаптация под все 4 темы (исключены темные нечитаемые шрифты).
   - Цветные бейджи влияния на старт: 🔴 **Высокое**, 🟡 **Среднее**, 🟢 **Низкое**, ⚪ **Отключено**.

5. **📊 Менеджер процессов**:
   - Интерактивное мгновенное переключение фильтров (Все процессы / 🟢 Безопасно завершить / 🟡 Пользовательские / 🔴 Системные Windows).

6. **🎨 Тема STORM NIGHT & Очистка интерфейса**:
   - Смягчены цвета кнопок в теме STORM NIGHT до сбалансированных, комфортных для глаз оттенков.
   - Убран переключатель тем из заголовка окна (выбор тем доступен в настройках).

## 🎨 4 Эксклюзивные темы оформления

1. **`STORM DARK`** (По умолчанию) — Кибер-тёмная тема (`#10141D`) с неоновыми акцентами электрического шторма (`#00D2FF`).
2. **`STORM NIGHT`** — Глубокий OLED чёрный (`#000000`) со сбалансированным кибер-свечением (`#00C2E8`).
3. **`STORM DAY`** — Дневная светлая тема (`#F4F7FB`) с высокой контрастностью.
4. **`STORM MIDNIGHT`** — Космическая фиолетовая тема (`#0C0A1D`) с неоновым свечением аметиста (`#A855F7`).

## 🛠️ Сборка из исходников

### Требования:
- Windows 10 (версия 1809+) или Windows 11
- .NET 8.0 SDK

### Команды для сборки:
```powershell
# Клонирование репозитория
git clone https://github.com/ReiKatari/STORM_SYSTEM_OPTIMIZER.git
cd STORM_SYSTEM_OPTIMIZER/Sources/StormSystemOptimizer

# Сборка Release
dotnet build -c Release

# Публикация автономного релиза (Self-Contained)
dotnet publish -c Release -r win-x64 --self-contained true -o "../../Assembling"
```

## 📦 Установка

Запустите установочный файл `Files\StormSystemOptimizer_Setup_v0.0.3.exe`:
- Автоматическая распаковка в `C:\Program Files\Storm System Optimizer`.
- Создание ярлыков на Рабочем столе и в меню «Пуск» с фирменной иконкой.
- Полная регистрация в реестре Windows с поддержкой чистого удаления через деинсталлятор.
