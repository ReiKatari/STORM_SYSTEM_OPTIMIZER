## ⚡ О проекте

**STORM SYSTEM OPTIMIZER v0.0.5** — это системный оптимизатор нового поколения на нативном движке **WPF (.NET 8 LTS)**. Программа проводит глубокий многопоточный анализ всей системы, предоставляет интерактивный менеджер процессов с базой знаний и рекомендациями, замер реальных температур комплектующих, аппаратные бенчмарки и безопасный стресс-тест с защитой от перегрева, диагностику накопителей и S.M.A.R.T. с оптимизацией TRIM/дефрагментацией, глубокую калибровку TCP/IP и DNS сетевого стека со встроенным тестом скорости (Speed Test), очищает скрытый мусор и оптимизирует службы без риска повреждения Windows.

## 🚀 Новые возможности и исправления в версии 0.0.5

1. **✨ Плавные анимации нажатия и мгновенный отклик кнопок**:
   - Во всей программе внедрены динамические эффекты масштабирования при нажатии (`0.96 scale`), неоновые границы при наведении и интерактивные баннеры обратной связи (на Панели состояния при сбросе DNS, оптимизации памяти, переключении планов электропитания и TRIM).
   - Исправлена работа каждой кнопки в разделах «Диски», «Сетевой стек», «Службы» и «Инструменты ОС».

2. **💾 Исправление диагностики накопителей и дефрагментации**:
   - Исправлены кнопки «Анализ тома» и «Оптимизировать / Дефрагментировать» для всех выбранных разделов дисков.
   - Устранены темные артефакты плашек статусов: добавлены высококонтрастные неоновые бейджи состояния (`Хорошее / Отличное / Внимание`) и фрагментации.

3. **📝 Полное отсутствие обрезания текста и аккуратный перенос**:
   - Разделы «Тестирование и бенчмарки», «Стресс-тест», «Датчики температур», «Глубокое сканирование», «Ускорение интернета» и «Менеджер процессов» переведены на адаптивный перенос текста (`TextWrapping="Wrap"`). Полные названия процессоров, видеокарт, накопителей, описания категорий и процессов теперь отображаются целиком без многоточий (`...`).

4. **🇷🇺 Чистая русская локализация без английских дубликатов в скобках**:
   - Удалены все английские термины в скобках после русских названий во всех окнах, кнопках, меню и всплывающих подсказках (`ПРОЦЕССОР`, `ОПЕРАТИВНАЯ ПАМЯТЬ`, `СИСТЕМНЫЙ ДИСК`, `Внешний IP`, `Интернет-провайдер`, `Скорость загрузки`, `Скорость отдачи`, `Рекомендуемый`, `Игровой`, `Экстремальный` и др.).

5. **🔍 Точный динамический перерасчет освобождаемого объема**:
   - В разделе «Глубокое сканирование» после оптимизации выбранных элементов их размер мгновенно пересчитывается в `0 Б`, счетчики найденного мусора обновляются в реальном времени, а статус переключается на «Оптимизировано успешно».

6. **⚙️ Стабильность и динамические статусы служб Windows**:
   - Полностью настроено переключение профилей служб («Рекомендуемый», «Игровой», «Экстремальный», «По умолчанию»). Устранены возможные сбои, настроена правильная цветовая индикация работающих, остановленных и отключенных служб.

7. **🛡️ Вшитый инсталлятор и цифровая подпись Authenticode**:
   - Готовый автономный установщик `StormSystemOptimizer_Setup_v0.0.5.exe` с автоимпортом корневого сертификата в доверенные хранилища Windows для запуска без блокировок Smart App Control.

## 🎨 4 Эксклюзивные темы оформления

1. **`STORM DARK`** (По умолчанию) — Кибер-тёмная тема (`#10141D`) с неоновыми акцентами электрического шторма (`#00D2FF`) и кристально белым текстом.
2. **`STORM NIGHT`** — Глубокий OLED чёрный (`#000000`) со сбалансированным кибер-свечением (`#00C2E8`).
3. **`STORM DAY`** — Дневная светлая тема (`#F4F7FB`) с высокой контрастностью.
4. **`STORM MIDNIGHT`** — Космическая фиолетовая тема (`#0C0A1D`) с неоновым свечением аметиста (`#A855F7`).

## 🛠️ Сборка из исходников

### Требования:
- Windows 10 (версия 1809+) или Windows 11
- .NET 8.0 SDK

### Команды для сборки:
```powershell
# Клонирование репозитория
git clone https://github.com/ReiKatari/STORM_SYSTEM_OPTIMIZER.git
cd STORM_SYSTEM_OPTIMIZER

# Сборка и упаковка релиза v0.0.5
powershell -ExecutionPolicy Bypass -File .\build_v005.ps1
```
