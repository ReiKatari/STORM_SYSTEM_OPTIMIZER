## ⚡ О проекте

**STORM SYSTEM OPTIMIZER v0.1.4** — это системный оптимизатор нового поколения на нативном движке **WPF (.NET 8 LTS)**. Программа проводит глубокий многопоточный анализ всей системы, предоставляет интерактивный менеджер процессов с деревом процессов и заморозкой, модуль **Удаления программ** с вычисткой хвостов в реестре и AppData, защищенный сейф **Скрытия и защиты папок** (3 режима), модуль **Обновления драйверов** с экспортом бэкапов и базой WHQL, детальную **Информацию о системе** по всем комплектующим, замер реальных температур комплектующих, тепловое влияние процессов на GPU/CPU, полный набор аппаратных бенчмарков (видеокарта GPU Direct3D, VRAM, процессор Multi/Single-Core, RAM, диск последовательный и 4K IOPS, STORM PERFORMANCE INDEX), безопасный стресс-тест с термозащитой, игровой режим **STORM GAME BOOST** с субмиллисекундным таймером прерываний (0.5 мс), режим **MSI (Message Signaled Interrupts)** для GPU и USB, тюнинг **DirectStorage 1.2 & BypassIO**, очистку **Standby Memory** ядра, встроенный **DNS Benchmark**, сетевой экран **Blackhole Shield**, **Smart Autopilot Daemon** и компактный игровой **HUD Оверлей (Ctrl+Shift+O)**.

## 🚀 Новые возможности и улучшения в версии 0.1.4

1. **🎮 Исправлен и прокачан HUD Оверлей (Ctrl+Shift+O)**:
   - Добавлена защита от закрытия, кнопка `✕`, перетаскивание в любую точку экрана, отображение FPS, загрузки CPU, RAM и температур GPU в реальном времени.
2. **💽 Новый раздел «Обновление драйверов» (Driver Updater)**:
   - Сканирование драйверов видеокарты, сети, аудио, чипсета и накопителей, сверка с базами WHQL, создание резервных копий всех установленных драйверов (`pnputil /export-driver`) и переход к центрам загрузок производителей.
3. **💻 Новый раздел «Информация о системе» (Hardware Specs & Diagnostics)**:
   - Исчерпывающая сводка по процессору (сокет, кэш L1/L2/L3, VT-x), видеокарте (VRAM, драйвер, монитор Hz), оперативной памяти (DDR4/DDR5, частота, производители модулей), материнской плате, накопителям, сети, аудио и безопасности ОС с экспортом в TXT.
4. **🔒 Прокачано «Скрытие папок» (Folder Locker & Vault)**:
   - Исправлены стили ComboBox для темных тем, добавлены подсказки в полях ввода, поддержка перетаскивания Drag & Drop и кнопка открытия в Проводнике.
5. **🎨 Настоящие иконки приложений в темных темах**:
   - Во всех списках (Тепловое влияние, Удаление программ) отображаются извлеченные цветные иконки и логотипы запущенных процессов и игр.
6. **🛡️ Автоматические точки восстановления Windows (Backup Engine)**:
   - Интегрировано создание точек восстановления перед важными оптимизациями, деинсталляцией и обновлением драйверов.
   - Автоматическое распознавание активных 3D-игр.
   - Выделение приоритета и привязка к производительным P-Cores, фоновая изоляция сторонних процессов на E-Cores.
8. **⏱️ Аппаратный таймер прерываний Windows (0.500 мс)**:
   - Включение субмиллисекундного таймера через `NtSetTimerResolution` для исключения микрофризов и максимальной плавности.
3. **⚡ Режим MSI (Message Signaled Interrupts)**:
   - Перевод видеокарты и USB-контроллеров мыши/клавиатуры в режим MSI на шине PCIe для снижения Input Lag.
4. **🪟 DWM Latency Tweak**:
   - Оптимизация композиции DWM и очередей кадров для 3D приложений.
5. **🧠 Очистка Standby Memory & Modified Page List**:
   - Вызов низкоуровневого API ядра `NtSetSystemInformation` для мгновенного освобождения кэша памяти без сброса рабочих данных.
6. **🗜️ Smart RAM Auto-Compressor**:
   - Сжатие памяти неактивных приложений с освобождением физической RAM для активного окна.
7. **🚀 DirectStorage 1.2 & NVMe BypassIO Tuning**:
   - Оптимизация очередей `Win32 IoRing` и прямого доступа к хранилищу для мгновенной загрузки игр.
8. **⏱️ Интеллектуальный Idle-TRIM**:
   - Автоматический TRIM SSD в периоды системного простоя.
9. **🌐 TCP NoDelay & Nagle’s Algorithm Toggle**:
   - Отключение задержки сетевых пакетов для минимизации онлайн-пинга.
10. **⚡ Smart DNS Benchmark & 1-Click Fast Switcher**:
    - Замер задержек DNS (Cloudflare, Google, Quad9, AdGuard) и переключение в 1 клик.
11. **🛡️ Сетевой экран Blackhole Shield**:
    - Блокировка серверов телеметрии и рекламы на уровне сети.
12. **🤖 Фоновый автопилот STORM (Smart Daemon)**:
    - Автоматический контроль температур, утечек памяти и состояния системы.
13. **🔄 Мастер контрольных снимков реестра (Snapshot & Rollback)**:
    - Резервное копирование и откат параметров в 1 клик.
14. **📊 Компактный игровой оверлей (STORM Mini HUD `Ctrl+Shift+O`)**:
    - Полупрозрачный экранный виджет поверх всех окон (FPS, CPU/GPU, температуры, RAM).
15. **📈 Детальный мониторинг по ядрам процессора (Per-Core Load)**:
    - Индивидуальная раскладка нагрузки по всем потокам и ядрам CPU.
16. **📄 Экспорт диагностического отчета системы в HTML/PDF**:
    - Формирование стильного темного отчета со всей спецификацией и показателями ПК.
