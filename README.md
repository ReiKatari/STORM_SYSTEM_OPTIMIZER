## ⚡ О проекте

**STORM SYSTEM OPTIMIZER v0.3.6** — системный оптимизатор нового поколения, разработанный на нативном высокопроизводительном движке **WPF (.NET 8 LTS)**. Программа предоставляет комплексный набор из 20 специализированных инструментов для глубокой настройки, ускорения игр, освобождения оперативной памяти ядра, устранения системных задержек и поддержания максимальной стабильности ПК.

---

## 🚀 20 Интеллектуальных разделов и возможностей

### 1. ⚡ Панель состояния (Dashboard) & Экспресс-буст
- Мониторинг CPU, RAM (включая Standby-кэш), системных накопителей и времени аптайма в реальном времени.
- Индикатор **DPC Latency** в микросекундах (предотвращение микростаттеров в играх и аудио-сбоев).
- Виджет игрового пинга до серверов **Valve, Riot, EA, Blizzard**.
- Быстрый переключатель планов питания (**STORM ULTIMATE PLAN** / Сбалансированный).
- Кнопка **«STORM BOOST»** — мгновенная очистка оперативной памяти ядра и сброс DNS в 1 клик.

### 2. 🔍 Быстрое сканирование (Scanner)
- Многопоточный анализ системного мусора (Windows Temp, User Temp, Prefetch, Crash Dumps, Windows Error Reporting, кэши браузеров, Delivery Optimization).
- Освобождение Standby-листа и Modified Page List через нативные системные вызовы ядра Windows NT.
- Классификация рисков: `[100% БЕЗОПАСНО]`, `[РЕКОМЕНДУЕТСЯ]`, `[ПРОДВИНУТЫЙ]`.

### 3. 🎛️ Менеджер процессов (Process Manager)
- Дерево процессов с выделением реального потребления памяти и дескрипторов.
- Привязка к производительным ядрам (**CPU Affinity P-Cores**) и изоляция сторонних фоновых задач на E-Cores.
- Управление парковкой ядер (**Core Parking**).
- Мгновенная приостановка и возобновление процессов (**Freeze / Thaw**).

### 4. ⚙️ Оптимизация служб Windows (Services Optimizer)
- Готовые профили: *Игровой (Game)*, *Экстремальный (Extreme)*, *Сбалансированный (Balanced)* и *Стандартный Windows*.
- Безопасное отключение скрытой телеметрии (`DiagTrack`, `dmwappushservice`, `RemoteRegistry`, `WerSvc`, `MapsBroker`).

### 5. 🚀 Менеджер автозагрузки (Startup Manager)
- Анализ влияния приложений на скорость старта Windows (High / Medium / Low).
- Удобное отключение автозапуска без риска удаления системных файлов.

### 6. 🔒 Приватность и телеметрия (Privacy Shield)
- Отключение сбора диагностических данных (`AllowTelemetry`), Advertising ID, Activity History и фонового трекинга.
- Блокировка синхронизации метаданных и скрытых журналов Windows.

### 7. 🗑️ Удаление программ (App Uninstaller)
- Глубокая деинсталляция программ, классических Win32 и UWP-приложений Windows.
- Автоматическая доочистка оставшихся хвостов в реестре, AppData и ProgramData.

### 8. 🌐 Ускорение интернета и DNS (Network & DNS)
- Отключение алгоритма Nagle и активация **TCP NoDelay** для ультра-низкого сетевого пинга.
- Интерактивный **DNS Benchmark** (Comss.one, Яндекс.DNS, Xbox & Gaming Fast DNS, Cloudflare, Google, AdGuard, Quad9).
- Мгновенный свитчер DNS с реактивным переключением активного адаптера.
- Сетевой экран **Blackhole Shield** для фильтрации рекламных и трекинговых хостов.

### 9. 🎮 Игровой режим (STORM GAME BOOST)
- Включение аппаратного субмиллисекундного таймера прерываний Windows (**0.500 мс** через `NtSetTimerResolution`).
- Перевод видеокарты GPU и контроллеров USB в режим **MSI (Message Signaled Interrupts)** на шине PCIe.
- Тюнинг задержек композиции DWM и очередей кадров.

### 10. 💽 Диски и Оптимизация (Storage Optimizer)
- Низкоуровневый Win32 драйвер опроса `IOCTL_STORAGE_GET_DEVICE_NUMBER` (мгновенный опрос без задержек).
- Отображение **точных заводских моделей производителей** для каждого физического диска и тома (NVMe M.2 SSD, SATA SSD, HDD, Storage Spaces ReFS).
- Контроль SMART-здоровья, температур, запуск оптимизации TRIM и анализ фрагментации.

### 11. 📦 Обновление программ (Software Updater)
- Сканирование установленного софта и версий в реестре и `Program Files`.
- Интеграция с официальным репозиторием Microsoft **Winget** (`winget upgrade --silent`).
- Автоматическое завершение блокирующих процессов и тихая фоновая установка апдейтов в один клик.

### 12. 🔄 Обновление драйверов (Driver Updater)
- Сканирование видеокарт, чипсета, сетевых карт, аудио и контроллеров накопителей.
- Экспорт и полное резервное копирование всех установленных драйверов системы (`pnputil /export-driver`).
- Прямой переход к официальным центрам загрузок WHQL производителей.

### 13. 📊 Датчики и Бенчмарки (Benchmarks & Sensors)
- Мониторинг температур CPU, GPU и накопителей в реальном времени.
- Безопасный стресс-тест с термозащитой (Auto-Stop при превышении порога).
- Тестирование 3D GPU (Direct3D FPS), CPU Single/Multi-Core, RAM пропускной способности, Disk 4K IOPS и расчет **STORM PERFORMANCE INDEX**.

### 14. 💻 Информация о системе (System Info)
- Полный аппаратный отчет: сокет процессора, кэш L1/L2/L3, VT-x/SVM, видеопамять VRAM, частота и тайминги RAM, свойства материнской платы, TPM 2.0, HVCI.
- Экспорт спецификации в форматированный **TXT** и стильный темный **HTML-отчет**.

### 15. 🔧 Настройки BIOS (BIOS Optimizer)
- Экспертные рекомендации по оптимизации прошивки: активация XMP/EXPO профилей памяти, ReBAR / Smart Access Memory, Above 4G Decoding, отключение ненужных контроллеров.

### 16. 🛠️ Инструменты ОС (System Tools)
- Быстрый запуск системных утилит в один клик: DISM Восстановление образа, SFC Проверка файлов, Панель God Mode, Очистка диска cleanmgr, Редактор локальной групповой политики.

### 17. ⚡ Тюнинг питания и ядер (Power & CPU Tuning)
- Интеграция и активация официального плана **STORM ULTIMATE PLAN**.
- Живой статус-бейдж парковки ядер (**Парковка ядер: ОТКЛЮЧЕНА (100% ядер активны)**).
- Оптимизация задержек переключения состояний C-States.

### 18. 🖱️ Оптимизация задержки ввода (Input Lag)
- Активация прямого ввода **1:1 Raw Input** (полное отключение скрытой акселерации и кривых сглаживания Windows).
- Ускорение отклика клавиатуры (KeyboardSpeed 31, Delay 0).
- Приоритет мультимедиа и системного планировщика прерываний.

### 19. 🖱️ Редактор контекстного меню (Context Menu Editor)
- Мгновенное переключение между классическим стилем Windows 10 и новым меню Windows 11.
- Очистка лишних пунктов («3D Edit», «ModernSharing»).
- Включение удобных команд: *«Открыть в Блокноте»*, *«Копировать путь к файлу»*, *«Панель управления God Mode»*, *«Открыть Командную строку здесь»*.

### 20. 🛡️ Центр бэкапов (Backup Vault)
- Автоматическое и ручное создание системных точек восстановления (**STORM_OPTIMIZATION_RESTOREPOINT**).
- Резервные копии снимков реестра (**STORM_REGISTRY_BACKUP**).
- Прямой запуск отката настроек и пошагового мастера восстановления Windows (`rstrui.exe`).

## 🔒 Цифровая подпись и безопасность
Все бинарные файлы и инсталляторы подписываются цифровым сертификатом Authenticode SHA-256 (`CN=STORM Software Root CA`).
Приложение не содержит сторонних библиотек сомнительного происхождения и выполняет только документированные, безопасные системные вызовы Windows NT.
