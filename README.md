<h1 align="center">STORM SYSTEM OPTIMIZER</h1>

## **О проекте**
STORM SYSTEM OPTIMIZER — флагманский программный комплекс для глубокой настройки, оптимизации аппаратных прерываний (DPC/ISR Latency), очистки, безопасности, развертывания программного обеспечения и ускорения операционных систем Windows 10 и 11. Включает готовые профили под процессоры Intel и AMD, оптимизацию оперативной памяти, видеокарт NVIDIA GeForce и AMD Radeon, маршрутизацию прерываний по ядрам CPU, модерацию USB (XHCI IMOD), сетевую приоритизацию QoS DSCP 46, дефрагментацию баз данных SQLite и нативный центр развертывания Microsoft Office.

## **Происхождение и форки**
Оригинальная комплексная разработка, объединяющая авторские алгоритмы оптимизации Windows, методы низкоуровневого анализа оборудования и проверенные инструменты системного обслуживания.

## **Технологический стек**
- **Языки программирования**: C# (.NET 8.0 / .NET 9.0), C++, PowerShell
- **Интерфейс**: WPF, XAML, динамическая мультитематическая система (Cyberpunk, Matrix, Midnight, Dark, Fantasy, Warhammer, Day)
- **Системные API**: Windows Registry, Service Control Manager (SCM), Windows Task Scheduler API, WMI, BCDEDIT, Powercfg, DirectX/NVIDIA Driver API, Windows Defender Firewall COM API, Click-to-Run (C2R) Deployment Engine

## **Ключевые возможности**
- **Диспетчер прерываний DPC/ISR и привязка ядер CPU**: Изоляция видеокарты, сетевого адаптера и USB/аудио контроллеров по выделенным ядрам процессора для полного устранения микрофризов и задержек DPC.
- **Модерация прерываний USB (XHCI IMOD)**: Тонкая калибровка интервалов прерываний USB для мгновенного отклика игровых мышей с частотой опроса 1000, 4000 и 8000 Гц.
- **Приоритизация игрового трафика QoS (DSCP 46)**: Назначение наивысшего сетевого приоритета Expedited Forwarding для пакетов соревновательных онлайн-игр (CS2, Valorant, Apex Legends, Dota 2, PUBG).
- **Оптимизация баз данных SQLite**: Дефрагментация (VACUUM) и перестроение индексов (REINDEX) для Chromium-браузеров, Mozilla Firefox, Telegram Desktop, Discord и Steam.
- **Центр безопасности и аудита**: Легковесный сканер скрытых криптомайнеров, аудит и зачистка сиротских правил Брандмауэра Windows и гарантированный шредер файлов (DoD 5220.22-M).
- **Центр Microsoft Office**: Выборочное C2R-развертывание Microsoft Office 2016–2024 / 365 с официальных серверов CDN Microsoft, исключение телеметрии Teams/OneDrive, менеджер KMS/GVLK лицензий и глубокая принудительная зачистка.
- **Таймеры BCD и кванты планировщика**: Настройка параметров `tscsyncpolicy`, `disabledynamictick`, фиксация CUDA P-State 0 и квантов `Win32PrioritySeparation`.
- **Резервное копирование и точки восстановления**: Автоматическое создание точек восстановления Windows и бэкапов реестра перед внесением любых изменений.

## **Поддерживаемые платформы**
- **Операционные системы**: Windows 10 (20H2–22H2), Windows 11 (21H2–24H2) x64

## **Установка и запуск**
1. Скачайте инсталлятор `STORM_SYSTEM_OPTIMIZER_2.1.0_Setup.exe` или архив `STORM_SYSTEM_OPTIMIZER_2.1.0.zip` из секции **Releases** на GitHub.
2. Запустите приложение от имени Администратора.
3. Выберите желаемые модули тюнинга, пресетов прерываний или компонентов развертывания.
4. Перезагрузите компьютер для вступления аппаратных твиков в силу.
