## ⚡ О проекте

**STORM SYSTEM OPTIMIZER** — комплексный программный комплекс для глубокой диагностики, очистки, ускорения и тонкой настройки операционных систем Windows 10 и Windows 11. Приложение построено на базе современной архитектуры **MVVM** с использованием **C# 12/.NET 8 LTS** и прямого взаимодействия с низкоуровневыми API ядра Windows NT (`ntdll.dll`, `kernel32.dll`, `rstrtmgr.dll`, Win32 IOCTL).

Все операции оптимизации строго классифицированы по уровням безопасности, сопровождаются автоматическим созданием резервных точек восстановления и не нарушают целостность системных компонентов.

## 🚀 Полный каталог 34 разделов и функций программы

### 1. ⚡ Панель состояния (Dashboard) и Экспресс-буст
- **Мониторинг аппаратных ресурсов в реальном времени**: непрерывное отслеживание загрузки CPU, оперативной памяти (включая Standby-кэш и пул ядра), активных накопителей и времени непрерывной работы (Uptime).
- **Индикатор системной задержки (DPC Latency)**: замер аппаратных задержек в микросекундах для предотвращения аудио-рассинхронизации, щелчков и микрофризов в играх.
- **Игровой сетевой пинг**: живой виджет отклика до ключевых игровых дата-центров (Valve CS2/Dota 2, Riot Valorant/LoL, EA Apex/FC, Blizzard Battle.net).
- **Мгновенный свитчер планов питания**: переключение в 1 клик между официальным энергопрофилем **STORM ULTIMATE PLAN** и сбалансированным режимом.
- **Кнопка «STORM BOOST»**: одновременная очистка Standby-листа RAM ядра, сброс кэша DNS и приоритезация активного окна.

### 2. 🔍 Глубокое сканирование и оптимизация (Scanner)
- **12+ категорий глубокого анализа**: очистка `Windows Temp`, `User Temp`, `Prefetch`, аварийных дампов памяти `Crash Dumps`, отчетов об ошибках Windows Error Reporting (WER), временных файлов доставки `Delivery Optimization`, кэшей браузеров и шейдеров.
- **Освобождение памяти NT**: вызов нативных функций ядра `NtSetSystemInformation` для очистки списков Standby List и Modified Page List.
- **Классификация рисков**: цветовая маркировка каждой категории (`[100% БЕЗОПАСНО]`, `[РЕКОМЕНДУЕТСЯ]`, `[ПРОДВИНУТЫЙ]`) с описанием и выборочной очисткой.

### 3. 🎛️ Диспетчер процессов (Process Manager)
- **Интерактивное дерево процессов**: отображение фактического потребления RAM, дескрипторов (Handles), потоков (Threads) и родительских деревьев.
- **CPU Affinity и архитектура Intel Hybrid**: привязка критических игр к производительным ядрам (**P-Cores**) и изоляция фоновых приложений на энергоэффективных ядрах (**E-Cores**).
- **Управление парковкой ядер (Core Parking)**: принудительная активация всех ядер процессора без ухода в сон при высоких нагрузках.
- **Заморозка процессов (Freeze / Thaw)**: мгновенная приостановка работы тяжелых фоновых задач с последующим быстрым возобновлением.

### 4. ⚙️ Оптимизация служб Windows (Services Optimizer)
- **Интеллектуальные профили настройки**:
  - *Игровой профиль (Gaming)* — отключение фоновых сервисов, освобождение ОЗУ и ресурсов процессора.
  - *Экстремальный профиль (Extreme)* — максимальный отклик для киберспортивных дисциплин.
  - *Сбалансированный профиль (Balanced)* — баланс быстродействия и фоновых служб.
  - *Стандартный Windows* — возврат к заводским настройкам Microsoft.
- **Безопасное отключение телеметрии**: адресное управление службами `DiagTrack`, `dmwappushservice`, `RemoteRegistry`, `WerSvc`, `MapsBroker`, `WbioSrvc` без риска повреждения системы.

### 5. 🚀 Менеджер автозагрузки (Startup Manager)
- **Оценка влияния на запуск**: автоматический расчет рейтинга нагрузки на старт Windows (*High*, *Medium*, *Low*).
- **Управление всеми источниками**: мониторинг реестра (`HKLM`/`HKCU` `Run`, `RunOnce`), папок автозапуска (`Startup`) и запланированных задач Windows Task Scheduler.

### 6. 🛡️ Центр конфиденциальности (Privacy Shield)
- **Отключение телеметрии и слежки Windows**: блокировка рекламного ID, журнала действий, телеметрии ввода текста и биометрии.
- **Отключение фонового сбора данных**: отключение диагностических отчетов Cortana, Windows Error Reporting и скрытых трекеров браузера Edge.

### 7. 🗑️ Деинсталлятор приложений (App Uninstaller)
- **Удаление классического Win32 софта и UWP-приложений**: полное удаление встроенного предустановленного софта Windows (Bloatware) без остаточного мусора.
- **Поиск скрытых хвостов**: сканирование реестра и каталогов `ProgramData`, `AppData` на наличие забытых файлов и ключей.

### 8. 📦 Обновление программного обеспечения (Software Updater)
- **Фоновый аудит версий софта**: проверка установленного ПО через Windows Package Manager (Winget).
- **Тихое обновление в 1 клик**: пакетное и выборочное обновление программ без интерактивных диалоговых окон инсталляторов.

### 9. 💽 Диагностика и обслуживание накопителей (Disks & S.M.A.R.T.)
- **Точные аппаратные данные Win32 IOCTL**: опрос физических дисков NVMe, SATA SSD и HDD без использования медленного WMI.
- **Индикаторы ресурса и здоровья**: температура накопителей, выработка ресурса SSD (TBW), процент оставшейся жизни.
- **Оптимизация TRIM**: принудительная отправка нативной команды TRIM для поддержания максимальной скорости записи SSD.

### 10. 📊 Стресс-тестирование и бенчмарки (Benchmarks & Sensors)
- **Комплексные тесты производительности**:
  - *CPU Multi-Core & Single-Core* — многопоточный стресс-тест целочисленных вычислений и алгоритмов плавающей запятой.
  - *RAM Read / Write Throughput* — замер реальной скорости чтения/записи оперативной памяти и латентности.
  - *Disk IOPS & Bandwidth* — последовательные и случайные 4K операции ввода/вывода.
- **Аппаратные датчики в реальном времени**: частота ядер, вольтаж, температура процессора и графического чипа.

### 11. 🌐 Ускорение интернета и DNS Тюнинг (Network & DNS)
- **DNS Benchmark**: одновременный опрос и замер задержки серверов Cloudflare (1.1.1.1), Google (8.8.8.8), Quad9 (9.9.9.9), AdGuard DNS и OpenDNS с возможностью мгновенного применения быстрейшего.
- **Оптимизация сетевого стека**: включение алгоритмов BBR/CTCP, отключение Nagle's Algorithm (TCP NoDelay), оптимизация MTU и RWIN.

### 12. 📁 Защита личных папок (Folder Protection)
- **Изоляция каталогов от модификаций**: блокировка несанкционированного доступа программ-вымогателей (Ransomware) к пользовательским папкам.
- **Шифрование и скрытие**: безопасное управление правами NTFS Access Control List (ACL).

### 13. 🔌 Обновление драйверов и устройств (Driver Updater)
- **Аудит оборудования через PnPUtil**: инспекция всех системных устройств и версий установленных драйверов.
- **Резервное копирование драйверов**: экспорт драйверов видеокарты, чипсета, сетевых контроллеров и аудио в отдельную папку для быстрого восстановления.

### 14. ℹ️ Полная спецификация ПК (System Information Pro)
- **Детальный аудит компонентов**: подробная информация о процессоре, материнской плате, оперативной памяти (XMP/EXPO тайминги, слоты), видеокарте, аудиочипе и сетевых интерфейсах.
- **Экспорт отчетов**: сохранение полной спецификации конфигурации в форматах TXT и HTML.

### 15. 🧬 Оптимизатор BIOS и Материнских плат (BIOS Optimizer Pro)
- **Персонализация под вашу плату**: автоматическое определение производителя (ASUS, MSI, Gigabyte, ASRock, EVGA, NZXT, Colorful, Biostar, Maxsun, Machinist, Huananzhi, Jingsha, Soyo) и вывод точных названий разделов и опций BIOS конкретно для установленной платы.
- **Рекомендации по киберспортивной настройке**:
  - *Активация XMP / EXPO / DOCP* — раскрытие номинальной частоты ОЗУ.
  - *Включение Resizable BAR (ReBAR / SAM)* — прямой доступ процессора ко всему объёму видеопамяти.
  - *Настройка C-States и Power Delivery* — минимизация DPC-задержек и скачков напряжения.
  - *Отключение CSM (Compatibility Support Module)* — ускорение UEFI-инициализации и включение Secure Boot.

### 16. ⚡ Быстрое обслуживание (Quick Maintenance)
- **Комплексная очистка в 1 клик**: очистка системного мусора, освобождение ОЗУ, очистка DNS, проверка системных служб и оптимизация визуальных эффектов за одно нажатие.

### 17. 🛠️ Инструменты и порты ОС (System Tools & Active Ports)
- **Стилизованный монитор активных портов**: интерактивная таблица сетевых сокетов TCP/UDP с цветными бейджами протоколов, статусов (LISTENING, ESTABLISHED, TIME_WAIT), PID и процессами.
- **Глубокие утилиты ОС**: быстрый запуск групповых политик `gpedit.msc`, расширенного реестра `regedit`, очистки компонентов DISM, проверки дисков CHKDSK и целостности SFC.
- **Военный шредер файлов (File Shredder / DoD 5220.22-M)**: многопроходное безвозвратное уничтожение файлов без возможности восстановления.
- **Очистка пустых папок**: рекурсивный поиск и безопасное удаление пустых каталогов на дисках.

### 18. 🔋 Тюнинг питания и процессора (Power & CPU Tuning)
- **Управление парковкой ядер**: тонкая настройка скрытых параметров реестра Windows для распределения нагрузок на ядра.
- **Режимы энергосбережения**: отключение Throttling'а питания на настольных ПК для стабилизации фреймрейта в соревновательных играх.

### 19. 🎯 Оптимизация задержки ввода (Input Lag Optimizer)
- **USB Polling Rate**: приоритезация шины контроллеров мыши и клавиатуры.
- **Отключение фильтрации ввода**: сглаживание кривой отклика мыши и удаление скрытого GameDVR.

### 20. 📑 Контекстное меню Windows (Context Menu Tweaks)
- **Возврат классического меню Windows 10 в Windows 11**: отключение медленного многослойного меню Windows 11 в 1 клик.
- **Добавление полезных утилит**: быстрый доступ к перезапуску Проводника, открытию Командной строки от имени Администратора и блокировке файлов.

### 21. 🛡️ Центр резервных копий (Backup & Restore Vault)
- **Точки восстановления Windows (VSS Restore Points)**: создание снимков состояния системы перед применением твиков и откат в случае необходимости.
- **Экспорт и импорт реестра**: создание резервных копий веток реестра.

### 22. ⚡ Оптимизация задержек аудио и MMCSS (Audio Latency & MMCSS)
- **Multimedia Class Scheduler Service (MMCSS)**: выделение гарантированной квоты процессорного времени (90%+) игровым и аудио-потокам.
- **Устранение треска звука**: синхронизация драйверов звуковых карт Realtek, ASUS Xonar, Creative Sound Blaster, Focusrite и USB-DAC.

### 23. 🔌 Управление питанием USB и опрос контроллеров (USB Polling)
- **Отключение выборочного отключения USB (USB Selective Suspend)**: предотвращение микрозадержек и отключения мыши в ответственные игровые моменты.
- **MSI-режим для USB-контроллеров**: перевод портов ввода в режим сигнальных прерываний.

### 24. 🧠 Управление памятью и файлом подкачки (Memory Master Pro)
- **Интеллектуальный расчет файла подкачки**: автоматический расчет оптимального начального и максимального размера `pagefile.sys` с учетом объема физической RAM и накопителя.
- **Выровненный интерфейс настроек**: удобный выбор целевого диска, установка фиксированных размеров и очистка Standby-кэша NT в реальном времени.

### 25. 🚀 Тюнинг и очистка браузеров (Browser Turbo & Cache)
- **Глубокая очистка кэшей**: освобождение гигабайтов временных данных Google Chrome, Microsoft Edge, Mozilla Firefox, Yandex Browser, Opera и Brave.
- **Сжатие баз данных SQLite**: дефрагментация внутренних баз браузеров для мгновенного запуска и снижения потребления памяти.

### 26. 🎮 Менеджер игровых лаунчеров (Game Launchers Manager)
- **Поддержка всех ключевых клиентов**: Steam, Epic Games Launcher, Battle.net, EA App, Ubisoft Connect, VK Play, GOG Galaxy, Riot Client, Wargaming Game Center, RetroArch.

- **Очистка кэшей шейдеров и веб-компонентов**: освобождение сотен мегабайт мусора CEF-кэша лаунчеров.

### 27. 🎮 Anti-Stutter движок и Gaming Tweaks
- **Отключение MPO (Multiplane Overlay)**: устранение мерцания экрана, черных экранов и разрывов кадров на видеокартах NVIDIA GeForce и AMD Radeon.
- **Оптимизация VBS и изоляции ядра (Hyper-V HVCI)**: освобождение до 15% вычислительной мощности CPU за счет безопасного переключения изоляции ядра.

- **Расширение кэша шейдеров DirectX и NVIDIA**: установка квоты 10 ГБ для предотвращения статтеров при компиляции шейдеров в играх на движке Unreal Engine 5.
- **Отключение скрытого GameDVR и оптимизация FSO**: снятие задержек полноэкранной оптимизации Windows.

### 28. 📂 Проводник и оболочка Windows (Explorer Tweaks)
- **Ускорение навигации**: мгновенное открытие папок, скрытие неиспользуемых системных папок и библиотек.
- **Отключение рекламы**: удаление рекламных баннеров OneDrive, советов и подсказок в окнах Проводника.

### 29. 🎨 Визуализация и DWM Тюнинг (Visual Performance)
- **Баланс графики и FPS**: оптимизация эффектов прозрачности Windows, сглаживания экранных шрифтов (ClearType) и анимаций сворачивания.
- **Тюнинг DWM (Desktop Window Manager)**: снижение задержек буферизации оконного менеджера при игре в оконном режиме без рамок.

### 30. 🛡️ Управление защитником и безопасность (Defender Tweaker)
- **Управление доверенными зонами**: добавление папок игр и оптимизатора в исключения Windows Defender для исключения просадок FPS при фоновом сканировании файлов во время игры.
- **Стилизованный неоновый регулятор квоты CPU (AvgCPULoadFactor)**: гибкое ограничение нагрузки Защитника до безопасных 5–15% с визуальным бейджем и шкалой баланса.
- **Защита от ложных блокировок**: предотвращение ложных срабатываний SmartScreen на доверенные локальные утилиты.

### 31. ⏱️ Профайлер загрузки Windows (Boot Profiler)
- **Анализ времени старта**: расчет времени инициализации ядра NT, загрузки драйверов устройств и пользовательского сеанса.
- **Тюнинг быстрого запуска**: настройка технологии Fast Startup и файла гибернации `hiberfil.sys`.

### 32. 🔄 Очистка компонентов Windows Update (Update Component)
- **Сжатие и очистка хранилища WinSxS**: безопасное удаление устаревших копий системных библиотек после установки обновлений Windows.
- **Сброс SoftwareDistribution**: исправление зависших и поврежденных загрузок Центра обновлений Windows.

### 34. 🔓 Разблокировка файлов и папок (File & Folder Unlocker Pro)
- **Прямой перехват дескрипторов (Restart Manager API)**: освобождение заблокированных файлов через нативный Win32 API (`rstrtmgr.dll`) без перезагрузки системы.
- **Интерактивная таблица блокировок**: вывод имен процессов, PIDs, путей исполняемых файлов и заголовков окон.
- **Действия в 1 клик**:
  - *Принудительная разблокировка* — закрытие дескрипторов и освобождение доступа.
  - *Разблокировать и удалить* — мгновенное стирание с отложенным удалением через `MoveFileEx(MOVEFILE_DELAY_UNTIL_REBOOT)` при перезагрузке ядра.
  - *Разблокировать и переименовать* — безопасное переименование занятых системных файлов.
  - *Разблокировать и переместить* — мгновенный перенос в целевой каталог.
  - *Завершить процессы* — адресное закрытие только конфликтующих процессов.
- **Интеграция в контекстное меню Windows**: интеграция пункта «Разблокировать в STORM» в меню правой кнопки мыши для всех файлов, папок и дисков.
- **Drag-and-Drop Dropzone**: перетаскивание заблокированных файлов прямо в окно программы.
