## ⚡ О проекте

**STORM SYSTEM OPTIMIZER v0.0.4** — это системный оптимизатор нового поколения на нативном движке **WPF (.NET 8 LTS)**. Программа проводит глубокий многопоточный анализ всей системы, предоставляет интерактивный менеджер процессов с базой знаний и рекомендациями, замер реальных температур комплектующих, аппаратные бенчмарки и безопасный стресс-тест с защитой от перегрева, диагностику накопителей и S.M.A.R.T. с оптимизацией TRIM/дефрагментацией, глубокую калибровку TCP/IP и DNS сетевого стека со встроенным тестом скорости (Speed Test), очищает скрытый мусор и оптимизирует службы без риска повреждения Windows.

## 🚀 Новые возможности и исправления в версии 0.0.4

1. **🌡️ Отображение реальных температур всех комплектующих**:
   - Живые датчики температуры CPU (ядра/сокета через WMI, ACPI и Performance Counters), видеокарты (GPU), твердотельных накопителей (NVMe/SATA SSD/HDD) и материнской платы (VRM/System).
   - Индикация на главной панели состояния и в специализированном разделе бенчмарков.

2. **🔬 Тестирование компонентов и безопасный стресс-тест**:
   - **Комплексные бенчмарки**: многопоточный тест CPU (математика, SHA256 и AES криптография), скорость оперативной памяти RAM (ГБ/с), последовательное чтение/запись системного диска (МБ/с).
   - **Безопасный стресс-тест**: выбор длительности (15с / 30с / 60с) с **автоматическим термо-отключением при 88°C** для абсолютной безопасности железа.

3. **🌐 Прокачка «Ускорения интернета» & Встроенный Speed Test**:
   - **Живая сетевая телеметрия**: отображение внешнего IP (WAN), страны/города, провайдера (ISP), локального IP, шлюза, типа сетевого адаптера и скорости линка.
   - **Встроенный тест скорости**: измерение реальной скорости загрузки (Download Мбит/с), отдачи (Upload Мбит/с), пинга (Ping мс) и джиттера (Jitter мс).
   - Мгновенная смена DNS на сверхбыстрые защищенные серверы (Cloudflare, Google, Quad9, AdGuard) и калибровка TCP/IP Auto-Tuning/ECN.

4. **🔍 Прокачка «Глубокого сканирования»**:
   - Новые расширенные категории глубокого исследования: кэш обновлений Windows Update (`SoftwareDistribution`), Delivery Optimization, кэш скомпилированных шейдеров GPU (NVIDIA DX/GLCache, AMD DxCache, DirectX D3DSCache), дампы системных сбоев (`MEMORY.DMP`, Minidump) и кэши браузеров (Chrome, Edge, Yandex, Opera, Firefox).

5. **🛠️ Прокачка «Инструментов ОС» и «Приватности»**:
   - Проверка целостности системных файлов (`sfc /scannow`), восстановление образа Windows (`DISM RestoreHealth`), очистка устаревших компонентов хранилища WinSxS, сброс сетевого каталога Winsock и перестроение кэша иконок/эскизов Проводника.
   - Глубокое отключение телеметрии, рекламного идентификатора, истории активности Timeline, кейлоггер-сбора рукописного ввода и поисковых подсказок Bing в меню «Пуск».

6. **🎨 100% Белая типографика и подсветка активных состояний**:
   - Все серые неконтрастные шрифты в темных темах заменены на чистый белый цвет (`#FFFFFF` / `#F8FAFC`).
   - Менеджер процессов: активные кнопки фильтрации подсвечиваются ярким неоновым контуром.
   - Службы Windows: активный профиль подсвечивается неоном, исправлено перекрытие уведомлений.
   - Диски и оптимизация: текст описания аккуратно переносится и не наезжает на кнопки.
   - Модальные окна `StormMessageBox` теперь центрируются строго по центру окна программы.
   - Локализация «Официальный релиз».

7. **🛡️ Встроенные сертификаты безопасности и готовый инсталлятор**:
   - Автоматический импорт Authenticode SHA-256 сертификата (`STORM Software Root CA`) в доверенные хранилища системы при установке для идеального запуска без блокировок Smart App Control.

## 🎨 4 Эксклюзивные темы оформления

1. **`STORM DARK`** (По умолчанию) — Кибер-тёмная тема (`#10141D`) с неоновыми акцентами электрического шторма (`#00D2FF`) и кристально белым текстом.
2. **`STORM NIGHT`** — Глубокий OLED чёрный (`#000000`) со сбалансированным кибер-свечением (`#00C2E8`).
3. **`STORM DAY`** — Дневная светлая тема (`#F4F7FB`) с высокой контрастностью.
4. **`STORM MIDNIGHT`** — Космическая фиолетовая тема (`#0C0A1D`) с неоновым свечением аметиста (`#A855F7`).

## 🛠️ Сборка из исходников

### Требования:
- Windows 10 (версия 1809+) или Windows 11
- .NET 8.0 SDK

### Команды для сборки:
```powershell
# Клонирование репозитория
git clone https://github.com/ReiKatari/STORM_SYSTEM_OPTIMIZER.git
cd STORM_SYSTEM_OPTIMIZER/Sources/StormSystemOptimizer

# Сборка Release
dotnet build -c Release

# Публикация автономного релиза (Self-Contained)
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o "../../Assembling"
```
