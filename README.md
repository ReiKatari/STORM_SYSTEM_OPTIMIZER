## ⚡ О проекте

**STORM SYSTEM OPTIMIZER v1.0.3** — комплексный программный комплекс для глубокой диагностики, очистки, ускорения и тонкой настройки операционных систем Windows 10 и Windows 11. Приложение построено на базе современной архитектуры **MVVM** с использованием **C# 12/.NET 8 LTS** и прямого взаимодействия с низкоуровневыми API ядра Windows NT (`ntdll.dll`, `kernel32.dll`, Win32 IOCTL).

Все операции оптимизации строго классифицированы по уровням безопасности, сопровождаются автоматическим созданием резервных точек восстановления и не нарушают целостность системных компонентов.

## 🚀 Полный каталог 33 разделов и функций программы

### 1. ⚡ Панель состояния (Dashboard) и Экспресс-буст
- **Мониторинг аппаратных ресурсов в реальном времени**: непрерывное отслеживание загрузки CPU, оперативной памяти (включая Standby-кэш и пул ядра), активных накопителей и времени непрерывной работы (Uptime).
- **Индикатор системной задержки (DPC Latency)**: замер аппаратных задержек в микросекундах для предотвращения аудио-рассинхронизации, щелчков и микрофризов в играх.
- **Игровой сетевой пинг**: живой виджет отклика до ключевых игровых дата-центров (Valve CS2/Dota 2, Riot Valorant/LoL, EA Apex/FC, Blizzard Battle.net).
- **Мгновенный свитчер планов питания**: переключение в 1 клик между официальным энергопрофилем **STORM ULTIMATE PLAN** и сбалансированным режимом.
- **Кнопка «STORM BOOST»**: одновременная очистка Standby-листа RAM ядра, сброс кэша DNS и приоритезация активного окна.

### 2. 🔍 Глубокое сканирование и оптимизация (Scanner)
- **12+ категорий глубокого анализа**: очистка `Windows Temp`, `User Temp`, `Prefetch`, аварийных дампов памяти `Crash Dumps`, отчетов об ошибках Windows Error Reporting (WER), временных файлов доставки `Delivery Optimization`, кэшей браузеров и шейдеров.
- **Освобождение памяти NT**: вызов нативных функций ядра `NtSetSystemInformation` для очистки списков Standby List и Modified Page List.
- **Классификация рисков**: цветовая маркировка каждой категории (`[100% БЕЗОПАСНО]`, `[РЕКОМЕНДУЕТСЯ]`, `[ПРОДВИНУТЫЙ]`) с описанием и выборочной очисткой.

### 3. 🎛️ Диспетчер процессов (Process Manager)
- **Интерактивное дерево процессов**: отображение фактического потребления RAM, дескрипторов (Handles), потоков (Threads) и родительских деревьев.
- **CPU Affinity и архитектура Intel Hybrid**: привязка критических игр к производительным ядрам (**P-Cores**) и изоляция фоновых приложений на энергоэффективных ядрах (**E-Cores**).
- **Управление парковкой ядер (Core Parking)**: принудительная активация всех ядер процессора без ухода в сон при высоких нагрузках.
- **Заморозка процессов (Freeze / Thaw)**: мгновенная приостановка работы тяжелых фоновых задач с последующим быстрым возобновлением.

### 4. ⚙️ Оптимизация служб Windows (Services Optimizer)
- **Интеллектуальные профили настройки**:
  - *Игровой профиль (Gaming)* — отключение фоновых сервисов, освобождение ОЗУ и ресурсов процессора.
  - *Экстремальный профиль (Extreme)* — максимальный отклик для киберспортивных дисциплин.
  - *Сбалансированный профиль (Balanced)* — баланс быстродействия и фоновых служб.
  - *Стандартный Windows* — возврат к заводским настройкам Microsoft.
- **Безопасное отключение телеметрии**: адресное управление службами `DiagTrack`, `dmwappushservice`, `RemoteRegistry`, `WerSvc`, `MapsBroker`, `WbioSrvc` без риска повреждения системы.

### 5. 🚀 Менеджер автозагрузки (Startup Manager)
- **Оценка влияния на запуск**: автоматический расчет рейтинга нагрузки на старт Windows (*High*, *Medium*, *Low*).
- **Управление всеми источниками**: мониторинг реестра (`HKLM`/`HKCU` `Run`, `RunOnce`), папок автозапуска (`Startup`) и запланированных задач Windows Task Scheduler.

### 6. 🛡️ Центр конфиденциальности (Privacy Shield)
- **Отключение телеметрии и слежки Windows**: блокировка рекламного ID, журнала действий, телеметрии ввода текста и биометрии.
- **Отключение фонового сбора данных**: отключение диагностических отчетов Cortana, Windows Error Reporting и скрытых трекеров браузера Edge.

### 7. 🗑️ Деинсталлятор приложений (App Uninstaller)
- **Удаление классического Win32 софта и UWP-приложений**: полное удаление встроенного предустановленного софта Windows (Bloatware) без остаточного мусора.
- **Поиск скрытых хвостов**: сканирование реестра и каталогов `ProgramData`, `AppData` на наличие забытых файлов и ключей.

### 8. 📦 Обновление программного обеспечения (Software Updater)
- **Интеграция с каталогом Windows Package Manager (Winget)**: тихое пакетное обновление установленных браузеров, игровых платформ, мессенджеров и медиаплееров.
- **Проверка версий в 1 клик**: мгновенный опрос актуальных релизов с поддержкой автоматической установки.

### 9. 🖨️ Менеджер драйверов (Driver Manager)
- **Прямое взаимодействие с PnPUtil**: вывод полного списка сторонних драйверов OEM устройств (видеокарта, чипсет, аудио, сетевые адаптеры).
- **Экспорт и Резервное копирование**: создание полного бэкапа всех установленных драйверов в отдельную папку для быстрого восстановления после переустановки Windows.

### 10. 🌐 Оптимизация сети и TCP/IP (Network Optimizer)
- **Тюнинг игрового стека**: включение алгоритмов прямого подтверждения пакетов `TCP NoDelay` (отключение задержки Nagle's Algorithm) и `TCP DelAckTicks = 0`.
- **Бенчмарк DNS-серверов**: замер реального времени отклика в миллисекундах до Cloudflare (1.1.1.1), Google (8.8.8.8), Quad9 (9.9.9.9), AdGuard DNS и мгновенное применение лучшего.
- **Сброс сетевых кэшей**: быстрая очистка кэшей сопоставителя DNS (`ipconfig /flushdns`), ARP-таблиц и сброс сокетов Winsock.

### 11. 🎮 Игровой буст и Приоритет (Game Boost)
- **Высокоточный системный таймер (0.500 мс)**: перевод таймера планировщика Windows на разрешение `0.5 ms` через нативные вызовы `NtSetTimerResolution` для ликвидации дрожания кадров.
- **Режим STORM GAME BOOST**: принудительное выделение кванта времени процессора для активного окна игры, подавление фоновых приоритетов ввода/вывода и очистка кэша RAM.

### 12. 💾 Анализ дискового пространства и IOCTL (Disk Analyzer)
- **Низкоуровневый опрос Win32 IOCTL**: прямое обращение `IOCTL_STORAGE_QUERY_PROPERTY` для получения реального типа шины (NVMe, SATA, USB), физической скорости чтения/записи, статуса TRIM и состояния здоровья накопителей.
- **Интерактивная карта распределения памяти**: визуализация занятого объема дисков с быстрым переходом к очистке.

### 13. 📊 Бенчмарк и Стресс-тест ПК (Benchmark & Stress Test)
- **Безопасный стресс-тест**: нагрузочное тестирование с защитой от перегрева (Auto-Stop при достижении заданного температурного порога).
- **Комплексные тесты производительности**: 3D Direct3D тест (FPS), CPU Single/Multi-Core, RAM Speed & Latency, Disk Sequential & 4K IOPS с расчетом итогового рейтинга **STORM PERFORMANCE INDEX**.

### 14. 💻 Информация о системе (System Info)
- **Детальная аппаратная спецификация**: тип сокета процессора, размеры кэшей L1/L2/L3, статус виртуализации VT-x/SVM, объем и шина VRAM видеокарты, конфигурация каналов и тайминги RAM, модель материнской платы, версия BIOS, статус TPM 2.0 и HVCI.
- **Точные данные мониторов**: определение реальных моделей мониторов и разрешений экрана даже при подключении через аппаратные свитчи и разветвители.
- **Экспорт спецификации**: сохранение отчета в форматированный текстовый файл (**TXT**) или темный интерактивный **HTML-отчет**.

### 15. 🔧 Настройки BIOS и Рекомендации (BIOS Optimizer)
- **Интеллектуальный советник по прошивке**: экспертные подсказки по безопасной настройке параметров UEFI/BIOS с автоопределением материнской платы (ASUS, MSI, Gigabyte, ASRock).
- **22+ проверенных аппаратных рекомендаций**:
  - *Память (RAM)*: профили XMP 2.0/3.0 / AMD EXPO / DOCP, режим Gear 1 (1:1 IMC), Memory Context Restore (мгновенный старт DDR5), калибровка вторичных таймингов (`tRFC`, `tFAW`, `tREFI`) для ликвидации статтеров.
  - *Видеокарта (GPU)*: активация Resizable BAR & Above 4G Decoding, отключение встроенного видеоядра iGPU Multi-Monitor для разгрузки контроллера памяти.
  - *Процессор (CPU)*: Intel SpeedShift / AMD CPB, андервольтинг AMD PBO Curve Optimizer / Intel CPU Lite Load (снижение на 8–15°C), маршрутизация Intel Thread Director / CPPC Preferred Cores, фиксация шины BCLK (Disable Spread Spectrum), ограничение Package C-State Limit (C2/Auto).
  - *Шина PCIe & Накопители*: фиксация скорости PCIe Gen4/Gen5 Link Speed, отключение задержек шины PCIe ASPM, прямое DMA без трансляций (Disable VT-d / AMD IOMMU).
  - *Загрузка & Безопасность*: чистый UEFI GOP без CSM, аппаратный таймер Invariant TSC вместо HPET, аппаратный TPM 2.0 (fTPM/PTT) и Secure Boot для античитов.
  - *Охлаждение & Акустика*: калибровка кривых Smart Fan PWM (защита от троттлинга) и гистерезис вентиляторов (Fan Step-Up/Down Delay).
- **Экспорт и печать**: выгрузка персональной шпаргалки в текстовый файл и темный печатный HTML-бланк.

### 16. 🛠️ Системные инструменты и Твики ядра (System Tools & Anti-Stutter Engine)
- **Комплекс Anti-Stutter и плавности фреймтайма (Новое в v1.0.1)**:
  - *Отключение MPO (Multi-Plane Overlay)*: ликвидация мерцаний, микростаттеров и рассинхронизации на мониторах с разной частотой обновления (144+ Гц + 60 Гц).
  - *Оптимизация VBS и Изоляции ядра*: отключение накладных расходов гипервизора Hyper-V (VM-Exit) для возврата +5–15% FPS в играх.
  - *Синхронизация таймеров Invariant TSC & HPET*: перевод системных таймеров на неизменяемый аппаратный счетчик тактов для устранения микродрожания (Jitter).
  - *Расширение кэша шейдеров до 10 ГБ*: устранение повторных задержек компиляции шейдеров (PSO Stuttering) в DirectX 12 и Vulkan играх.
  - *Отключение GameDVR & Оптимизация FSO*: деактивация скрытого фонового захвата видео Windows и включение прямого аппаратного DirectFlip.
- **Быстрый запуск системных утилит**: DISM Восстановление хранилища компонентов, SFC Проверка целостности системных файлов, Панель God Mode, Очистка диска `cleanmgr`, Редактор локальной групповой политики `gpedit.msc`.
- **Снимок параметров (Snapshot и Rollback)**: создание моментального снимка критических веток реестра перед оптимизацией для быстрого отката.
- **Тюнинг ядра Windows**: оптимизация DirectStorage 1.2, BypassIO, очередей Win32 IoRing, игрового планировщика MMCSS и Win32 Priority Separation (0x1A).

### 18. 🖱️ Оптимизация задержки ввода (Input Lag)

### 26. 🔊 Аудио и Минимизация задержек звука (Audio Latency)
- **Оптимизация службы MMCSS (Multimedia Class Scheduler Service)**: выделение максимального квантового приоритета аудио-потокам реального времени.
- **Режим WASAPI Exclusive**: устранение аппаратного джиттера и задержек буферизации звуковых карт в играх и DAW-приложениях.
- **Борьба с рассинхронизацией**: устранение щелчков, заиканий и отставания звука в ресурсоемких сценах.

### 27. 🖱️ Опрос USB и Частота периферии (USB Polling)
- **Тюнинг контроллеров USB**: оптимизация работы корневых USB-концентраторов (xHCI/eHCI) для стабильной частоты опроса игровых мышей и клавиатур (1000 Гц, 4000 Гц, 8000 Гц).
- **Отключение выборочного энергосбережения**: предотвращение засыпания портов USB и микрозадержек при первом движении мыши.

### 28. 📁 Твики Проводника и Windows Shell (Explorer Tweaks)
- **Ускорение интерфейса**: устранение задержек открытия контекстных меню и анимаций окон (`MenuShowDelay = 0`).
- **Оптимизация поиска**: отключение онлайн-подсказок и веб-поиска Bing в меню «Пуск» для мгновенного локального поиска.
- **Отключение рекламы**: удаление рекламных баннеров OneDrive, советов и подсказок в окнах Проводника.

### 29. 🎨 Визуализация и DWM Тюнинг (Visual Performance)
- **Баланс графики и FPS**: оптимизация эффектов прозрачности Windows, сглаживания экранных шрифтов (ClearType) и анимаций сворачивания.
- **Тюнинг DWM (Desktop Window Manager)**: снижение задержек буферизации оконного менеджера при игре в оконном режиме без рамок.

### 30. 🛡️ Управление защитником и безопасность (Defender Tweaker)
- **Управление доверенными зонами**: добавление папок игр и оптимизатора в исключения Windows Defender для исключения просадок FPS при фоновом сканировании файлов во время игры.
- **Ограненные кнопки управления**: стильные элементы интерфейса с подтверждением действий и очисткой журнала угроз.
- **Защита от ложных блокировок**: предотвращение ложных срабатываний SmartScreen на доверенные локальные утилиты.

### 31. ⏱️ Профайлер загрузки Windows (Boot Profiler)
- **Анализ времени старта**: расчет времени инициализации ядра NT, загрузки драйверов устройств и пользовательского сеанса.
- **Тюнинг быстрого запуска**: настройка технологии Fast Startup и файла гибернации `hiberfil.sys`.

### 32. 🔄 Очистка компонентов Windows Update (Update Component)
- **Сжатие и очистка хранилища WinSxS**: безопасное удаление устаревших копий системных библиотек после установки обновлений Windows.
- **Сброс SoftwareDistribution**: исправление зависших и поврежденных загрузок Центра обновлений Windows.

## 🛠️ Сборка из исходного кода

### Требования к окружению:

- Установленный пакет **.NET 8.0 SDK** (или новее).

### Команда полной сборки и подписи:
```powershell
# Запуск конвейера компиляции, сборки установщика и цифровой подписи
```
